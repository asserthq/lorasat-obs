# Усиление напряжения для АЦП 

![[Pasted image 20261014165403.png]]

формула ОУ: K = 1 + R_f / R_g
пусть берем R_f = 33 кОм, R_g = 1 кОм
тогда K = 34, тогда V_out_max = 0.086 В * 34 = 2.92 В
в stm32f407 АЦП 12-битный, это 4096 отсчетов на 3.3 В
напряжению 2.92 В соответствует значение 3624

# Функции спутника
- маячит раз в 10 сек на 435 и 868 мгц
- принимает кадры от абонентов на 868 мгц
- принимает команды от НС на 435 мгц
- измеряет магнитное поле
- сохраняет телеметрию в память
- сохраняет данные абонентов в память
- отправляет накопленную телеметрию на НС по 435 мгц
- отправляет накопленные данные абонентов на НС по 868 мгц
- использует Watchdog-таймер

# Разбивка по подсистемам (задачам)
### СЭП
- измеряет напряжение АКБ
### БКУ
- маячит раз в 10 сек на 435 мгц
- сохраняет телеметрию в память
- отправляет накопленную телеметрию на НС по 435 мгц
- будит WDG
### ПН
- маячит раз в 10 сек на 868 мгц
- принимает кадры от абонентов на 868 мгц
- сохраняет данные абонентов в память
- отправляет накопленные данные абонентов на НС по 868 мгц
### СОС
- измеряет магнитное поле

# Периферия
- магнитометр MMC5983MA по I2C
- ==магнитометр 2 по I2C==
- гироскопы BMI088 (2 шт) по I2C
- ШИМ драйвер катушек X/Y (DRV8833)
- ШИМ драйвер катушки Z (DRV8833)
- аналоговые входы - измерение тока на катушках (3 входа)
- LoRa 435 МГц по SPI
- LoRa 868 МГц по SPI
- FLASH память W25Q64 по SPI
